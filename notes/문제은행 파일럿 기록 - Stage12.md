# Stage 12 — 발문 오류 수정 + <보기>/<자료> 제시 자료 추가 (Version 22, 2026-09-14)

사용자 요청 3건 중 앞의 두 가지를 처리했다(세 번째 "유사 유형 매핑"은 Stage 13에서 별도 진행 예정). "문제은행 파일럿 기록.md" 본문(Stage 1~11)에 이어지는 내용이며, 다음 세션에서 본문에 병합해도 좋다.

## 1) 발문(스템) 잔여 오류 3건 수정
- **417개 항목 소급 절단 수정**: 2022~2027학년도(17개 회차) `items_final.json`의 `발문` 값이, 더 이전에 이미 고쳐졌던 `parse_exam.py`의 줄 누적 로직(물음표 나올 때까지 계속 이어붙이기) 수정 이전 버전으로 생성된 채 남아 있었다 — 즉 코드는 고쳐졌지만 이미 만들어진 JSON은 재생성되지 않았던 것. 캐시된 원문(`/tmp/{y}_{mm}.txt`)에서 `build_items.build()`로 발문을 다시 뽑아 417개 항목의 `발문` 필드만 패치(다른 필드는 손대지 않음). 패치 전후 값이 항상 "확장"(접두사 일치) 관계임을 검증 후 적용, 최종적으로 1,492+45문항 전체 물음표 누락 0건 확인.
- **단어 위치 뒤섞임 3건**: PDF 컬럼 재조합 과정에서, 스타일이 다른(밑줄·강조 등으로 추정) 짧은 단어 하나가 원래 위치가 아니라 문항 발문의 다른 지점(선택지 직전 등)으로 밀려나 앉는 드문 결함을 3건 발견 — 정규식(발문 안의 "-적"류 낱말이 "것은" 바로 앞에 붙는 패턴, 그리고 번호 뒤에 조사만 있는 패턴)으로 전수 스캔해 찾아냈다.
  - `2027-09 독서 7`: "...가장 적절한 표준적 것은?" → 지문에서 "표준적 입장"이 실제로 쓰인 것을 확인해 "7. 표준적 입장의 관점에 따라 ㉠, ㉡을 이해한 것으로 가장 적절한 것은?"으로 정정(사용자가 원래 지목했던 바로 그 문항).
  - `2024-09 독서 1`: "1. 의 내용과 일치하지 않는 것은?" → "1. 윗글의 내용과 일치하지 않는 것은?"("윗글"이 누락돼 있었음 — 같은 패턴의 다른 문항들과 대조해 확인).
  - `2025-06 독서 5`: "5. 에 대한 이해로 적절하지 않은 것은?" → 지문에서 "과두제적 경영"이라는 용어가 실제로 쓰인 것을 확인해 "5. 과두제적 경영에 대한 이해로 적절하지 않은 것은?"으로 정정.
  - 전 29개 회차 원문 + 2028 예시문항 원문을 대상으로 같은 패턴("N.\n<짧은 단어>\n것은?" 형태) 재스캔 → 위 3건 외 추가 발견 없음.

## 2) <보기>/<자료>/<학습 활동> 등 제시 자료("보기") 신규 추가
- **추출 로직**: `parse_exam.py`에 발문 누적이 멈춘 지점부터, 문항 블록에서 "마지막으로 등장하는 ①"까지를 제시 자료로 보고 새 필드 `보기`를 추가(추출 후 `clean_bogi()`로 정리). 첫 구현에서 두 가지 버그를 발견·수정:
  1. **경계 미클램핑으로 인한 오염**: 문항 블록이 "다음 문항 시작 전까지"로만 잘려 있어(마커 클램핑 없음), 지문의 마지막 문항은 다음 지문 전체까지 블록에 포함되고, 그 다음 지문 안에 우연히 등장하는 "①"(예: 블로그 글 속 "[여행 ①]" 라벨)을 선택지 시작으로 잘못 집어 보기가 다음 지문 내용까지 통째로 삼키는 사고 발생(`2022-06 언어와 매체 39` 확인). → `extract_choices.py`의 `choices_in_zone()`과 동일하게 `min(다음 문항 시작, 다음 지문 마커 시작)`으로 블록을 클램핑하고, 찾아낸 마지막 "①" 뒤에 ①②③④⑤가 정확히 5개 이어지는지 검증하는 안전장치 추가.
  2. **"◦" 불릿 줄 통째 삭제 버그**: 재사용한 `clean_passage()`의 boilerplate 목록에 있던 "줄이 ◦로 시작하면 무조건 버림" 규칙이, 지문에서는 안전해도 보기/자료 박스에서는 개요·체크리스트 항목의 실제 불릿으로 흔히 쓰여(예: "◦카드 뉴스 보완 방향: ...") 내용 유실을 일으킴(`2022-09 화법과 작문 43` 확인). → `parse_exam.py`에 보기 전용 정리 함수 `clean_bogi()`를 새로 만들어 이 규칙만 제외(나머지 페이지 잔재 제거·문단 병합 로직은 동일하게 유지).
- **잡음 필터링**: 값이 있어도 실질적 내용이 없는 경우(예: "<보 기>"만 있고 실제 자료는 표/그림이라 텍스트가 없는 경우, "ⓐ ⓑ"처럼 밑줄 표시가 엉뚱한 위치로 떨어져 나온 부스러기, "[자료1] [자료2] [자료3]"처럼 라벨만 있는 경우)를 정규식으로 걸러 빈 문자열 처리(추측으로 채우지 않는다는 기존 원칙 유지).
- **2028 예시문항 세트**: `extract_2028_bogi.py`를 새로 작성해 같은 방식(첫 물음표 뒤 ~ 마지막 "①" 전, 마커 클램핑, 5개 검증)으로 추출. 다만 2, 20, 24번 문항은 "선택지가 밑줄 뒤 동그라미 번호로 끝에 붙는" 특수 구조(Stage 11에서 이미 발견한 유형)라 "①이 선택지 시작을 표시한다"는 기본 가정 자체가 성립하지 않아 이 세 문항만 보기를 빈 문자열로 처리(발문 뒤 내용 자체가 곧 선택지 목록이라 별도 보기가 없는 문항이기도 함).
- **최종 커버리지**: 2015 교육과정 1,492문항 중 525문항(약 35%), 2028 예시문항 45문항 중 14문항에서 확보. 나머지는 원래 별도 제시 자료가 없거나, 있어도 표/그래프/이미지로만 존재해 텍스트로 복구할 수 없는 경우(두 경우가 데이터만으로는 구분되지 않음 — Artifact 하단 안내에 명시).
- **UI**: `itemDetailHtml()`에서 발문과 선택지 사이에 "제시 자료" 라벨 + 박스(`bogi-box`/`bogi-text`, 지문 원문과 유사한 스타일이되 강조색 왼쪽 테두리로 구분)로 표시. 검색 결과 카드에는 넣지 않음(카드는 발문 수준 요약만 유지하는 기존 방침과 동일).
- 결과물: `items_final.json`/`items_2028_예시.json`에 `보기` 필드 추가(별도 파일 없음 — 두 파일 자체가 Artifact 빌드에 통째로 임베드되는 구조라 `build_problem_bank.py` 수정 불필요, `problem_bank_template.html`만 수정).
- 검증: JS 문법 오류 없음, U+FFFD 없음, `보기` 필드에 선택지 마커(①~⑤) 잔존 0건, 무작위 표본 20여 건 육안 검토로 원문과 대조해 문맥이 매끄럽게 이어짐을 확인.

# Stage 13 — 유형 → 역량 매핑(추론적 사고 등) 추가 (Version 23, 2026-09-14)

세 번째 요청("유사한 유형의 문항 매핑 — 추론적 사고가 요구되는 문항을 모두 제공")을 처리했다. Stage 12에서 "다음 세션 예정"으로 남겨 두었던 항목.

## 설계
- 기존 `유형` 필드는 출처마다(공식 정답 및 해설·EBS·사설 학원·자동 분류) 세분화 기준이 달라 총 320여 종(2015 세트 286종 + 2028 세트 41종, 중복 제외)으로 흩어져 있어 "비슷한 유형끼리 묶어 보기"에는 그대로 쓰기 어려움 — 그래서 `reform_mapping.py`의 `map_reform()`과 같은 패턴(키워드 정규식 매핑)으로 새 스크립트 `skill_mapping.py`를 작성해, 유형 문자열을 15개의 굵직한 "역량" 카테고리로 묶는 새 파생 필드 `역량`(배열)을 추가했다.
- `map_reform()`과 달리 **첫 매치 하나만 쓰지 않고 매치되는 규칙을 전부 모아 다중 태그**를 부여한다 — 한 문항이 여러 역량과 동시에 관련되는 경우가 흔하기 때문(예: "외적 준거에 따른 작품 감상"은 자료·사례 적용이면서 동시에 작품 감상). 사용자가 "'추론'으로 연관 있는 문항들이 묶인다"고 요청한 대로, 카테고리로 검색했을 때 관련 문항이 전부 걸리려면 다중 라벨이 맞다.
- 15개 역량: 추론적 사고, 세부 내용 파악, 비판적 평가·판단, 어휘·문맥적 의미, 문법 요소 이해·적용, 서술·전개 방식 파악, 인물·화자의 심리·태도 파악, 작품 감상(외적 준거), 자료·사례 적용, 비교·대조적 이해, 화법 전략(말하기), 작문 전략(글쓰기), 매체 활용·특성 파악, 계획·의도·맥락 반영 파악, 소재·배경·시어의 기능 파악.

## 규칙 검증
- 실제 존재하는 320종 유형 문자열 전수를 대상으로 커버리지를 확인하며 규칙을 반복 보강 — 처음에는 24종이 매핑되지 않았으나(예: "정보 간의 관계 파악", "구체적 상황에 적용하기", "시어, 시구의 의미와 기능 파악" 등 EBS/사설 학원 특유의 표현), 패턴을 넓혀 최종적으로 "미분류(수동 확인 필요)" 자체인 유형을 제외한 320종 전부 매핑 성공.
- "미분류(수동 확인 필요)"인 40개 문항(전체 1,537개 중)은 애초에 유형 자체가 확정되지 않아(자동분류값과 동일한 플레이스홀더) 매핑 근거가 없으므로 역량도 빈 배열로 남김 — 추측으로 채우지 않는다는 기존 원칙 유지.
- 최종: 1,537문항 중 1,497문항(약 97.4%)에 역량 태그 1개 이상 부여(1개 1,314건·2개 174건·3개 8건·4개 1건). 역량별 문항 수는 세부 내용 파악(365)·자료·사례 적용(192)·작품 감상(129)·매체 활용·특성 파악(121)·문법 요소 이해·적용(109)·작문 전략(108)·인물·화자의 심리·태도 파악(101)·화법 전략(100)·추론적 사고(95, 사용자가 예로 든 카테고리) 등.
- 무작위 표본으로 "추론적 사고" 태그가 붙은 문항 육안 검토 — "세부 정보 추론", "생략된 내용/정보 추론", "이유로 적절한 것" 등 실제로 추론을 요구하는 발문과 일치함을 확인.

## UI
- 상단 필터 영역에 "역량으로 찾기" 칩 행 신설(area 칩과 같은 토글 방식, 여러 개 선택 시 OR 매칭 — 그중 하나라도 해당하면 표시). 검색·연도별 배너(회차 보기) 양쪽 모두에서 동작(`matches()`에 `역량` 교집합 검사 추가).
- 문항 상세(`badgesHtml()`)에 역량 태그를 강조색 배지로 함께 표시해, 어떤 역량으로 분류됐는지 바로 보이게 함(검색 결과 카드·회차 보기 상세 양쪽 모두).
- 모드 전환(전개년 ↔ 2028 예시문항)·회차 보기 진입·필터 초기화 시 역량 선택도 함께 초기화되도록 기존 리셋 로직에 통합.
- 하단 안내에 "역량으로 찾기" 방법론 설명 문단 추가(매핑 원칙·다중 태그 이유·커버리지 수치 명시).

## 결과물
