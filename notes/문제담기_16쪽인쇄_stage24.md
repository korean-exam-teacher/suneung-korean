# Stage 24 — 문제 담기 · 모아 풀기 · 16쪽 시험지 인쇄 (Version 43~44)

빌드: `python3 merge_v40.py` (site_v39.html + v40/basket.css + v40/basket.js → site_v40.html), 게시 시 explain.json 함께, capabilities `{downloads: true}`.
코드 전문: `claude/stage24_basket_pipeline.txt`

## 기능
- 문항 펼침 → "＋ 문제 담기" 토글. 회차 화면 지문 머리에 "이 지문 문항 모두 담기/빼기".
- 위 메뉴 "담은 문제"(개수 배지). 목록은 localStorage `kbank-basket-v1`(이 브라우저에만 저장).
- 같은 지문 문항은 한 묶음(지문 1번만), 번호는 담은 순서대로 1번부터 새로 매김. 묶음 ↑↓, 묶음 빼기, 문항 빼기, "영역 순으로 정리"(독서→문학→화작→언매), 모두 비우기.
- 모아 풀기: 지문+문항 이어서 풀기, 풀이 시간, "한꺼번에 채점하기"(점수·틀린 번호 바로가기, 오답 노트 기록).
- 시험지 인쇄: 2단 시험지형(첫 쪽 "국어 영역" 제목·성명/번호 칸, 이후 쪽 머리글·쪽 번호). 용지 A4/B4, 글자 자동 맞춤(10.5→8.5pt) 또는 고정. 브라우저에서 실제로 쪽을 나눠 쪽수를 계산하고 16쪽을 넘으면 인쇄 단추를 끔. 미리 보기, 정답표(쪽수와 별도), 원래 회차·번호 표시 선택.
- 인쇄: window.print()(인쇄 영역만 출력). 인쇄 창이 안 열리면 "인쇄용 파일 받기(.html)"(downloads 기능)로 같은 쪽 나눔 파일 저장.

## 검증 (Playwright, 대체 글꼴 환경)

- 한 회차 45문항(언매 제외): A4는 9~10pt로 16쪽, B4는 10.5pt로 12~15쪽 (2024·2025·2019·2012 수능, 2016 수능 B형).

## 한계·주의
- 지문 앞 지시문은 "다음 글을 읽고 물음에 답하시오."로 통일(원래 지시문과 다를 수 있음).
- "제시 자료가 비어 있음"은 발문이 <보기>를 가리키는데 자료 칸·지문에 없는 경우를 자동으로 찾은 것이라 그림·표 여부는 원본 확인 필요. 매체 지문 중 글자는 있지만 화면 일부가 그림인 경우는 자동으로 찾지 못함.
- 쪽수는 보는 기기의 글꼴로 계산되므로 기기마다 조금 다를 수 있음. 받은 .html 파일은 인터넷 연결 시 같은 글꼴로 나옴(로컬 글꼴을 고른 경우 그 글꼴이 있는 컴퓨터에서만 같음).
