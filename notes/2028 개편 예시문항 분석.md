# 2028학년도 수능 개편 예시문항 안내자료집 분석 (국어영역 중심)

출처: 한국교육과정평가원, 『2028학년도 대학수학능력시험 예시문항 안내』(2025년 4월 발간), 154쪽. 사용자가 업로드한 `2028예시문항안내자료집_최종.pdf` 전체를 분석.

## 1. 국어영역 개편의 핵심 구조 변화

- **선택과목 폐지**: 기존 "공통(독서·문학) + 선택(화법과 작문 / 언어와 매체)" 구조가 사라지고, 전 수험생이 **동일한 45문항**을 푼다. 더 이상 학생이 화작/언매 중 하나를 고르지 않는다.
- **과목 재편(2022 개정 교육과정 기준)**:
  - `화법과 언어` — 기존 화법과 작문의 '화법' + 언어와 매체의 '언어(문법)' 결합. 매체 관련 내용은 약화/통합됨.
  - `독서와 작문` — 기존 '독서' + 화법과 작문의 '작문' 결합.
  - `문학` — 기존과 동일하게 독립 과목 유지.
- **문항 배분(예시문항 기준, 정답표로 확인)**: 문항 1~10 화법과 언어(10문항), 11~30 독서와 작문(20문항), 31~45 문학(15문항) = 총 45문항. 시험시간 80분·100점은 기존과 동일 (2028 시간표(안)도 국어 08:40~10:00(80분)으로 변화 없음).
- **성취기준 코드 체계**: `[12화언XX-XX]`(화법과 언어), `[12독작XX-XX]`(독서와 작문), `[12문학XX-XX]`(문학). 기존 `[12화작XX-XX]`, `[12언매XX-XX]`, `[12독서XX-XX]`, `[12문학XX-XX]` 체계에서 화작·언매·독서가 재편된 것.
- **새로운 통합 문항 유형의 등장**: 화법과 언어 과목에서는 "화법+언어(문법)"를 하나의 지문·상황 안에서 함께 묻는 문항이 새로 등장 (예: 발표문에서 특정 표현의 문법적 특징과 화자의 태도를 함께 묻는 문항, 토의 상황에서 언어적 표현과 토의 전략을 함께 묻는 문항). 기존에는 화법/작문/언어/매체가 각 문항 단위로 비교적 분리되어 있었다면, 개편 후에는 화법과 언어가 한 문항 안에서 융합되는 경향이 뚜렷하다.
- **독서와 작문의 결합 방식**: 독서 지문을 읽고 그 내용을 바탕으로 "글을 쓰는 상황"에 적용하는 문항(예: 인터뷰 자료를 활용해 비평문 작성, 학생의 초고를 고쳐 쓰는 문항)이 다수 등장. 순수 독서 지문 이해 문항과, 독서+작문이 결합된 문항이 공존.
- **행동영역 분류(평가틀)**: 어휘·개념, 사실적 이해, 추론적 이해, 비판적 이해, 적용·창의 5개 — 기존 수능의 사실적/추론적/비판적 사고력 분류와 유사하되 '어휘·개념'과 '적용·창의'가 명시적으로 강조됨.

## 3. 부록 — 2028학년도 수능 예시문항 문제지·정답표 (국어영역, pp.91~107)

전체 45문항 실제 예시 시험지가 수록되어 있음(공식 정답·배점 포함). 문항 구성:
- 1~3번: 발표(어휘의 공공성) — 지문 있음
- 4~6번: 학생회 토의(후문 계단 안전사고)
- 7~10번: 단어 의미관계, 조어법, 표준 발음
- 11~13번: 디지털 영화 리얼리즘 (독서+비평문 작성)
- 14~17번: 정보 접근권한/접근제어목록
- 18~23번: 표현의 자유 vs 인격권 (가/나 두 글)
- 24~27번: 합리적 선택·기회비용·매몰비용 (가/나/다 논증문 초고)
- 28~30번: 소리 요법 체험 소감문 초고
- 31~33번: 고전소설 「옥루몽」류(홍 낭자·양 공자)
- 34~38번: 「적성가」(고전가사류, 이은영) + 우음체 시조
- 39~42번: 「도요새에 관한 명상」(김원일) — 공단 오염 문제를 다루는 현대소설, 생태주의 관점 학습활동 연계
- 43~45번: 「길」(김기림)+「한계」(천양희)+두 편 더 비교 감상(시간과 공간의 이미지화)

정답표(전 45문항 정답·배점)도 p.107에 전재되어 있음 — 필요시 `/home/claude/`에 정리 가능.

## 4. 부록 — 영역별 교육과정 근거 (국어, pp.137~140)

45문항 전체에 대해 문항번호 ↔ 성취기준(예: `[12화언01-11] 토의에서 주제와 관련된 다양한 자료를 통해 공동체의 문제를 분석하고 합리적으로 해결한다.`) 매핑표가 전재되어 있음. 이는 향후 "개편 대응 태그" 설계 시 성취기준 코드 체계를 그대로 가져다 쓸 수 있는 1차 자료.

## 5. 기존 문제은행(2026~2027학년도, 280문항)과의 매핑 설계안

기존에 구축한 데이터는 '영역' 필드가 독서/문학/화법과 작문/언어와 매체 4갈래이다. 2028 개편 대응을 위해 아래와 같은 **매핑 규칙(신유형 매핑)**을 제안한다.

| 기존 영역 | 신설 과목(2028) | 비고 |
|---|---|---|
| 독서 | 독서와 작문 | 그대로 이월 — 독서 지문·문항 성격 대부분 유지 |
| 문학 | 문학 | 그대로 이월 |
| 화법과 작문 — 화법 문항 | 화법과 언어 | 화법 부분만 이월 |
| 화법과 작문 — 작문 문항 | 독서와 작문 | 작문 부분은 독서와 작문 쪽으로 재배치 |
| 언어와 매체 — 언어(문법) 문항 | 화법과 언어 | 언어(문법) 부분만 이월 |
| 언어와 매체 — 매체 문항 | (경과조치 필요) | 신설 교육과정에서 매체 관련 성취기준이 화법과 언어 쪽에 일부만 잔존 — 매체 단독 문항은 개편 후 출제 비중이 크게 줄거나 화법과 언어에 부분 흡수될 것으로 추정. 문제은행에서는 별도 "매체(경과)" 태그로 남겨 학생들에게 "출제 비중 감소 예상" 안내 필요.

**실행 방안**: 문제은행 스키마에 `개편매핑_과목` 필드(화법과 언어 / 독서와 작문 / 문학 / 매체-경과)를 추가하고, 화법과 작문·언어와 매체 문항은 문항 단위로 위 표에 따라 수동 재분류한다. 현재 자동분류된 "유형" 태그(예: 화법-말하기방식, 작문-글쓰기전략, 매체활용 등)의 접두어를 활용하면 규칙 기반으로 1차 자동 매핑이 가능하다(예: "화법-"으로 시작 → 화법과 언어, "작문-"으로 시작 → 독서와 작문, "매체"가 포함 → 매체-경과, "문법"/"언어" 포함 → 화법과 언어).
