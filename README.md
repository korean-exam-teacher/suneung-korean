# 국어의 모든 것

국어 시험 기출 자료실입니다. 사이트 주소는 https://korean-exam-teacher.github.io/suneung-korean/ 입니다.

| 갈래 | 내용 |
|---|---|
| 불휘 기픈 남ᄀᆞᆫ (`suneung.html`) | 2009~2027학년도 평가원 6월·9월 모의평가·수능 국어, 2014학년도 예비 시행, 2022학년도 예시문항, 2028학년도 개편 예시문항. 지문 소재와 문항 유형으로 찾고 풀고 채점할 수 있습니다. 문학 문항은 싣지 않습니다. 대신 회차마다 원본 시험지 링크를 달았습니다. |
| ᄉᆡ미 기픈 므른 (`saemi.html`) | 대학별 인문·사회 논술(준비 중) |
| 곶 됴코 여름 하ᄂᆞ니 (`kkot.html`) | 공직적격성평가(PSAT) 언어논리, 법학적성시험(LEET) 언어이해·추리논증, 중등교사 임용시험 국어. 원본 문항 그림을 싣고, 답을 골라 채점할 수 있습니다. 문학 문항은 싣지 않습니다. |

비영리 교육 목적으로 만들었습니다. 수록 문항의 저작권은 각 시험 시행 기관(한국교육과정평가원, 법학전문대학원협의회, 인사혁신처 등)에 있습니다.

## 폴더

- `docs/`: GitHub Pages가 그대로 보여 주는 완성된 사이트입니다.
  - `pic/`: 원본 문제지에서 잘라 낸 문항 그림
  - `fig/`: 수능 문항 그림
  - `fonts/`: 옛한글 부분 글꼴
  - `media/`: 첫 화면 영상
- `build_v56/`: 화면·인쇄 양식 패치 프로그램입니다.

사이트를 만든 프로그램과 작업 기록은 저장소에 두지 않고 만든 사람이 따로 보관합니다.
